# Interest cues: what the creator loves, collects and makes, their pets, the
# milestones of their life and the family around them. Same format as
# cue-phrases.txt ("phrase | weight", multi-word only).
#
# Every phrase is general framing that works on any channel: it says HOW a
# person talks about an interest ("I collect", "I'm obsessed with"), never WHAT
# the interest is. Never add a topic, product or name from one creator here.
#
# These phrases join the transcript search, so the download already holds the
# passages they find. They do NOT re-weight the main ranking: a phrase new to
# the main list ranks there as weak framing (0.5). Their weight here ranks the
# reserved interest seats (fetch_cues.py --interest-seats), a separate set of
# seats filled after the main ranking, so interest passages are read without
# pushing out the life-story passages the main list chooses.
#   3   names a lasting interest, a collection, a pet, something they made,
#       a milestone or a family member
#   2   usually carries one
#   1   sometimes carries one
#
# A phrase already in cue-phrases.txt is never repeated here. Instead, the
# "@from-main" lines below make a whole section of that list count for the
# reserved seats too, at the weights it has there. That way a passage that
# only says "my dog" or "my husband", which the main ranking may leave unread,
# still gets a chance at an interest seat.
@from-main pets
@from-main family
@from-main habits / tastes / style
